02 / The person behind the code

Curious by nature.
Precise by practice.

I’m a final-year Diploma in Computer Science student in South Africa, drawn to the part of software you don’t always see: the logic that makes everything work.

I build practical projects that connect backend request handling, relational database design, user workflows, and mobile integration. My focus is Java, Servlets, JSP, SQL-backed systems, JPA concepts, and Android Kotlin.

I work across frontend, backend, databases, and deployment, with a growing emphasis on maintainable systems, clear structure, and realistic documentation.
